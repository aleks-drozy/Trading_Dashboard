**api.ts** -- Add two helper functions and a WatchlistItem interface at the end of the file:

```typescript
export interface WatchlistItem {
  symbol: string
  asset_type: string
}

export async function fetchWatchlist(): Promise<WatchlistItem[]> {
  const res = await fetchWithAuth('/watchlist')
  if (!res.ok) throw new Error('Failed to fetch watchlist')
  return res.json()
}

export async function addWatchlistSymbol(symbol: string, assetType: string = 'stock'): Promise<void> {
  const res = await fetchWithAuth('/watchlist', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ symbol, asset_type: assetType }),
  })
  if (!res.ok) {
    const data = await res.json().catch(() => ({}))
    throw new Error(data.detail || 'Failed to add symbol')
  }
}

export async function removeWatchlistSymbol(symbol: string): Promise<void> {
  const res = await fetchWithAuth(`/watchlist/${symbol}`, { method: 'DELETE' })
  if (!res.ok) {
    const data = await res.json().catch(() => ({}))
    throw new Error(data.detail || 'Failed to remove symbol')
  }
}
```

Component: `export function WatchlistSidebar({ signalSymbols }: { signalSymbols: string[] })`

Props:
- `signalSymbols: string[]` -- list of symbols currently present in the latest WebSocket signal broadcast. Used to determine if a newly added symbol has data yet (shows "awaiting data" label if not).

State:
- `items: WatchlistItem[]` -- current watchlist from server + optimistic additions
- `addValue: string` -- input field value
- `addError: string | null` -- inline error below input
- `loading: boolean` -- true during initial GET /watchlist fetch

**Loading state:** On mount, call `fetchWatchlist()`, set items, set loading=false. While loading, show `<p className="text-xs" style={{ color: '#6B7280' }}>Loading...</p>`.

**Empty state:** When items is empty and not loading, show:
- Heading: "No symbols" in text-sm font-semibold color #F1F5F9
- Body: "Add a ticker above to start tracking signals." in text-xs color #6B7280

**Add flow (handleAdd function):**
1. Trim and uppercase: `const sym = addValue.trim().toUpperCase()`
2. If empty, return (no error shown)
3. Client-side validation:
   - If sym already in items list: set addError to "Already in watchlist", return
   - If not matching `/^[A-Z0-9.]{1,10}$/`: set addError to "Invalid ticker format", return
4. Clear addError, clear addValue
5. Optimistic: `setItems(prev => [...prev, { symbol: sym, asset_type: 'stock' }])`
6. Try `await addWatchlistSymbol(sym, 'stock')`
7. On catch: rollback `setItems(prev => prev.filter(i => i.symbol !== sym))`, set addError to error message

**Remove flow (handleRemove function):**
1. Optimistic: `setItems(prev => prev.filter(i => i.symbol !== symbol))`
2. Try `await removeWatchlistSymbol(symbol)`
3. On catch: reload from server `fetchWatchlist().then(setItems)`, show toast via `toast.error(\`Failed to remove ${symbol}\`)`

**Input behavior:**
- value is `addValue`, onChange sets `addValue` to `e.target.value.toUpperCase()` (uppercase on every keystroke)
- onKeyDown: if Enter key, call handleAdd
- onChange also clears addError (set to null)
- placeholder: "Ticker e.g. SPY"
- aria-label: "Symbol ticker"

**Layout (matches UI-SPEC wireframe):**

Outer container: `className="flex flex-col"` with `style={{ width: 240, borderRight: '1px solid #2D3148', backgroundColor: '#0F1117', position: 'sticky', top: 56, height: 'calc(100vh - 56px)', overflowY: 'auto' }}`

Heading row: `<h2 className="text-sm font-semibold" style={{ color: '#F1F5F9' }}>Watchlist</h2>` followed by a `<div style={{ borderBottom: '1px solid #2D3148' }} className="mt-2 mb-2" />`

Add input row (below heading): flex row gap-2, Input (h-9, flex-1) + Button (size="sm", variant="default", aria-label="Add symbol") containing `<Plus className="w-4 h-4" />`

Inline error: `{addError && <p className="text-xs mt-1" style={{ color: '#EF4444' }} role="alert">{addError}</p>}`

Symbol list: `<div className="mt-3 flex flex-col gap-2">` mapping over items. Each row is a flex row justify-between items-center:
