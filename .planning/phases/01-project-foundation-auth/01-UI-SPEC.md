## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Input internal padding (vertical), button gap |
| md | 16px | Input internal padding (horizontal), form field gap |
| lg | 24px | Card internal padding, section gap |
| xl | 32px | Auth card outer margin, landing section gap |
| 2xl | 48px | Landing hero vertical rhythm |
| 3xl | 64px | Landing page section breaks |

Exceptions:
- Touch/click targets (Google OAuth button, nav links): minimum 44px height per WCAG 2.5.5
- Divider ("or continue with email") vertical margin: 24px top + bottom

## Typography

Exactly 4 sizes and 2 weights are declared for this phase.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Label | 14px | 400 | 1.4 | Inter | Input labels, helper text, nav links, button text, error messages, divider label, eyebrow labels, footer text, "Forgot password?" link, password hints |
| Body | 16px | 400 | 1.5 | Inter | Form subtext, paragraph copy, feature card body, hero subheading |

## Component Contracts

### Auth Card

The auth card is the shared wrapper for all auth pages (login, register, forgot-password, reset-password).

- Background: `#1a1a1a`
- Border: 1px solid `#2a2a2a`
- Border radius: 12px
- Padding: 32px (xl)
- Max-width: 400px
- Centered horizontally and vertically on the page
- Page background behind the card: `#0f0f0f`

### Text Input

- Background: `#0f0f0f`
- Border: 1px solid `#2a2a2a`
- Border radius: 8px
- Padding: 12px 16px (vertical: 12px, horizontal: 16px)
- Height: 44px
- Font: 16px Inter weight 400
- Placeholder color: `#6b7280`
- Focus state: border color changes to `#00ff88`, box-shadow `0 0 0 2px rgba(0,255,136,0.15)`
- Error state: border color `#ef4444`, box-shadow `0 0 0 2px rgba(239,68,68,0.15)`
- Transition: border-color 150ms ease, box-shadow 150ms ease

### Primary Button (accent)

- Background: `#00ff88`
- Text color: `#0f0f0f` (dark on light green)
- Font: 14px Inter weight 700
- Border radius: 8px
- Height: 44px
- Width: 100% (full-width in auth forms)
- Hover: background `#00e67a` (5% darker)
- Active: background `#00cc6a` (10% darker)
- Disabled: background `#1a3d2b`, text `#2a5a3a`, cursor not-allowed
- Loading state: spinner replaces text (see Loading States section)
- Transition: background 150ms ease

### Secondary Button (outline)

Used for "Back to sign in" links styled as buttons, and any non-primary action.

- Background: transparent
- Border: 1px solid `#2a2a2a`
- Text color: `#6b7280`
- Font: 14px Inter weight 400
- Border radius: 8px
- Height: 40px
- Hover: border-color `#4a4a4a`, text color `#9ca3af`

### Google OAuth Button

- Background: `#1a1a1a`
- Border: 1px solid `#2a2a2a`
- Text color: `#e5e7eb`
- Font: 14px Inter weight 400
- Border radius: 8px
- Height: 44px
- Width: 100%
- Google "G" SVG icon left of text, 20px × 20px, 8px gap between icon and text
- Hover: background `#242424`, border-color `#3a3a3a`
- Transition: background 150ms ease, border-color 150ms ease

### Divider ("or continue with email")

- Horizontal rule: 1px solid `#2a2a2a`
- Label text: "or continue with email"
- Label font: 14px Inter weight 400
- Label color: `#6b7280`
- Layout: two hr lines flanking the label, centered
- Margin: 24px top and bottom

### Inline Field Error

- Displayed below the input, immediately on blur if invalid (D-03)
- Font: 14px Inter weight 400, line-height 1.4
- Color: `#ef4444`
- Top margin: 8px from input bottom
- Prefix: none (no icon) — text only

### Loading Spinner

Used inside primary buttons during async operations (form submit, Google OAuth redirect).

- Replace button text with a spinner SVG
- Spinner: 18px × 18px, border 2px, color `#0f0f0f` on green background
- Animation: rotate 500ms linear infinite
- Button disabled while loading (pointer-events: none)
- No separate full-page loading overlay for auth forms

## Interaction Contracts

### Form Validation Timing (D-03)

- Validation triggers: **on blur** (when user leaves a field), NOT on input/keystroke
- Error message appears below the field immediately on blur if invalid
- If the user corrects the field and blurs again, the error clears
- On form submit: re-validate all fields client-side before sending the request
- Server-side errors (e.g. "Email already registered"): displayed as a banner above the form in a red `#ef4444` bordered box with 12px padding

### Loading States

- Primary button shows a spinner (18px rotating border SVG) in place of its text label during async operations
- Button is disabled (pointer-events: none, opacity 0.7) while loading
- No full-page loader or skeleton for auth pages
- Google OAuth button shows spinner while redirect is in progress (after click, before navigation)
- Duration estimate: any server round-trip that takes over 200ms should show the spinner

### Navigation Between Auth Pages

- "Forgot password?" on login page: plain link, navigates to `/forgot-password`
- "Back to sign in" on forgot-password/reset-password: navigates to `/login`
- "Sign up" on login page footer: navigates to `/register`
- "Sign in" on register page footer: navigates to `/login`
- All cross-auth navigation uses `next/link` (client-side navigation, no full reload)

### Post-Auth Redirects

- Successful login: redirect to `/dashboard` (D-01)
- Successful registration: auto-login, redirect to `/dashboard` (D-02)
- Successful password reset: redirect to `/login` with reset-success state shown inline on the reset-password page

### Google OAuth Flow

- Google button appears above email form, separated by the "or continue with email" divider (D-04)
- Clicking Google button triggers `signIn('google')` from NextAuth
- Google OAuth button shows spinner after click (loading state while redirect begins)
- On return from Google, NextAuth redirects to `/dashboard` (same post-login destination)

## Responsive Behavior

Scope: desktop-first per REQUIREMENTS.md UI-04. Auth pages are usable on tablet.

| Breakpoint | Auth pages | Landing page |
|------------|-----------|--------------|
| Desktop (≥1024px) | Auth card centered, max-w-400 | 3-column feature grid, full hero |
| Tablet (768–1023px) | Auth card centered, max-w-400, full-width at 90% viewport | 2-column feature grid (or 1-column if 3 cards don't fit), hero stacks |
| Mobile (<768px) | Not required — must not break, but not polished | 1-column features, hero stacks |

Auth card on tablet: padding reduces to 24px; card edge-to-edge with 16px margin each side below 480px.

## Accessibility Contract

- All inputs have associated `<label>` elements (not placeholder-only)
- Error messages linked to inputs via `aria-describedby`
- Buttons have visible focus rings (2px solid `#00ff88` at 40% opacity)
- Google OAuth button has `aria-label="Sign in with Google"`
- Color contrast: `#e5e7eb` on `#1a1a1a` = 12.9:1 (passes AAA)
- Color contrast: `#0f0f0f` on `#00ff88` (button text) = 15.3:1 (passes AAA)
- Color contrast: `#6b7280` on `#1a1a1a` = 4.8:1 (passes AA for normal text)
- Loading spinners have `aria-label="Loading"` and `role="status"`
