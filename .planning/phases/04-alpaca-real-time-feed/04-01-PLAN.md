2. Imports:
   ```python
   import asyncio
   import logging
   from datetime import datetime, timezone, timedelta
   from alpaca.data.live import StockDataStream
   from alpaca.data.historical import StockHistoricalDataClient
   from alpaca.data.requests import StockBarsRequest
   from alpaca.data.timeframe import TimeFrame, TimeFrameUnit
   from alpaca.data.enums import DataFeed

   ```

3. Constants:
   ```python
   WATCHDOG_TIMEOUT_SECONDS = 180  # 3 minutes
   BASE_BACKOFF_SECONDS = 5
   MAX_BACKOFF_SECONDS = 60
   ```

4. `class AlpacaFeed`:
   - `__init__(self, api_key: str, secret_key: str, symbols: list[str] | None = None, bar_store: BarStore | None = None, feed: DataFeed = DataFeed.IEX)` — stores all params; `self._bar_store = bar_store if bar_store is not None else _default_bar_store`; `self._last_bar_time: dict[str, datetime] = {}`
   - `_on_bar(self, bar)` — converts alpaca bar to project `Bar(timestamp=bar.timestamp, open=float(bar.open), high=float(bar.high), low=float(bar.low), close=float(bar.close), volume=float(bar.volume))`; gets current bars from store; deduplicates: `deduped = [b for b in current if b.timestamp != local_bar.timestamp]`; updates store with `(deduped + [local_bar])[-500:]`; records `self._last_bar_time[bar.symbol] = local_bar.timestamp`; logs info with symbol, timestamp, close price
   - `_check_watchdog(self, symbol: str)` — identical logic to BinanceFeed._check_watchdog: if `self._last_bar_time.get(symbol)` exists and age > WATCHDOG_TIMEOUT_SECONDS, log ERROR "WATCHDOG: No bar received for {symbol} in >3 minutes. Last: {last}"
   - `async def run(self)` — outer while True loop with exponential backoff. Inside: create `StockDataStream(api_key=self._api_key, secret_key=self._secret_key, feed=self._feed)`, call `stream.subscribe_bars(self._on_bar, *self.symbols)`, await `asyncio.create_task(stream._run_forever())`. On clean exit reset backoff to BASE_BACKOFF_SECONDS. Catch `asyncio.CancelledError`: call `stream.stop()`, re-raise. Catch `Exception`: log error, `await asyncio.sleep(backoff)`, `backoff = min(backoff * 2, MAX_BACKOFF_SECONDS)`.

5. `async def backfill_bars(api_key: str, secret_key: str, symbols: list[str], bar_store: BarStore, n_bars: int = 200)`:
   - Create `StockHistoricalDataClient(api_key=api_key, secret_key=secret_key)`
   - For each symbol: create `StockBarsRequest(symbol_or_symbols=symbol, timeframe=TimeFrame(1, TimeFrameUnit.Minute), start=datetime.now(timezone.utc) - timedelta(days=5), end=datetime.now(timezone.utc), limit=n_bars, feed="iex")`
   - Run `await asyncio.to_thread(lambda: client.get_stock_bars(request))`
   - Access bars: `bar_set.data.get(symbol, [])` (safe access pattern from research Open Question 1)
   - Convert each alpaca bar to project Bar, sort by timestamp
   - If bars exist: `bar_store.update(symbol, bars[-500:])`; log info "Backfilled {len(bars)} bars for {symbol}"
   - If no bars: log WARNING "Backfill returned no bars for {symbol}"
