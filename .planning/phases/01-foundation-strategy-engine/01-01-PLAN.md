**auth/service.py**:
```python
import jwt, bcrypt
from datetime import datetime, timezone, timedelta
from fastapi import HTTPException
from backend.config import get_settings

settings = get_settings()
ALGORITHM = "HS256"
TOKEN_EXPIRE_HOURS = 8

def verify_password(plain: str, hashed: str) -> bool:
    return bcrypt.checkpw(plain.encode(), hashed.encode())

def create_access_token(sub: str) -> str:
    payload = {
        "sub": sub,
        "exp": datetime.now(timezone.utc) + timedelta(hours=TOKEN_EXPIRE_HOURS),
    }
    return jwt.encode(payload, settings.secret_key, algorithm=ALGORITHM)

def decode_token(token: str) -> dict:
    try:
        return jwt.decode(token, settings.secret_key, algorithms=[ALGORITHM])
    except jwt.ExpiredSignatureError:
        raise HTTPException(status_code=401, detail="Token expired")
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="Invalid token")
```

**auth/router.py**:
- POST /auth/login: accepts `OAuth2PasswordRequestForm` (form data), checks email matches `settings.admin_email`, verifies password against `settings.admin_password_hash` using `verify_password`, returns `{"access_token": token, "token_type": "bearer"}` on success, raises `HTTPException(401, "Invalid credentials")` on failure.
- POST /auth/logout: returns `{"message": "Logged out"}` with 200. Token deletion is client-side — backend is stateless.
