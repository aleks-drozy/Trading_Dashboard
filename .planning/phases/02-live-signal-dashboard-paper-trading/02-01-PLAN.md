Create `backend/signals/broadcaster.py` with class `SignalBroadcaster`:
- `__init__(self)`: Initialize `self._clients: list[WebSocket] = []` and `self._engine = StrategyEngine()`
- `connect(self, ws: WebSocket) -> None`: Append ws to clients list
- `disconnect(self, ws: WebSocket) -> None`: Remove ws from clients list (use try/except ValueError for safety)
- `async broadcast(self, message: dict) -> None`: JSON-send message to all connected clients; on any exception for a client, disconnect that client silently (log warning)
- `async compute_and_broadcast(self) -> None`:
  1. Read watchlist symbols: open a Session(get_engine()), create WatchlistRepository, call get_all()
  2. For each symbol, get bars from `bar_store.get(symbol)`
  3. If len(bars) < 22 (need 20 for EMA warmup + 2 for IFVG), skip symbol
  4. Convert bars to pandas DataFrame with columns: open, high, low, close, volume (and timestamp as index)
  5. Call `self._engine.run(df)` to get StrategyResult
  6. Build per-symbol signal dict: `{"symbol": symbol, "ifvg_state": result.ifvg_state, "cisd_state": result.cisd_state, "ema_condition": result.ema_condition, "ema_value": result.ema_value, "updated_at": datetime.now(ZoneInfo("America/New_York")).isoformat()}`
  7. After all symbols processed, build broadcast payload: `{"type": "signal_update", "ny_session_active": is_ny_session_active(), "signals": [list of per-symbol dicts]}`
  8. Call `await self.broadcast(payload)`
- `async run(self, interval_s: float = 60.0) -> None`: Infinite loop: call `await self.compute_and_broadcast()`, then `await asyncio.sleep(interval_s)`. Wrap in try/except asyncio.CancelledError to exit cleanly. Wrap compute_and_broadcast in try/except Exception to log errors but keep loop alive.

Module-level singleton: `broadcaster = SignalBroadcaster()`
