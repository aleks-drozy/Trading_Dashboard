## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip internal padding, inline tight spacing |
| sm | 8px | Between form field groups, compact list row padding, badge padding |
| md | 16px | Default element spacing, form field vertical gap, card internal padding (compact) |
| lg | 24px | Section padding within form groups, filter bar height padding |
| xl | 32px | Card padding (standard, matching existing Card.tsx `p-8` = 32px) |
| 2xl | 48px | Between major page sections |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Touch targets: primary Button height is 44px, secondary Button height is 40px (verified from Button.tsx). Input height is 44px (verified from Input.tsx). These exact heights must be preserved on all interactive elements per existing component contracts.
- Sidebar width: 216px (within the 200–220px discretion range; Claude's Discretion per CONTEXT.md). Sidebar uses `w-[216px]` fixed width.
- P&L preview sticky bar: 48px height (`py-3` = 12px top + bottom + 24px content area).

Source: Button.tsx heights verified, Card.tsx p-8 = 32px, CONTEXT.md Claude's Discretion for sidebar width.

## Typography

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Body | Inter | 14px | 400 (regular) | 1.5 | Table cell text, filter labels, form helper text, nav link labels |
| Label | Inter | 14px | 500 (medium) | 1.4 | Form field labels (matching existing Input.tsx `text-sm`), section headings within cards |
| Heading | Inter | 20px | 600 (semibold) | 1.3 | Page titles (e.g. "Trade Log", "Add Trade"), card section titles |
| Display | Inter | 28px | 700 (bold) | 1.2 | Not used in Phase 3 — reserved for Phase 4 dashboard stats |
| Mono — value | JetBrains Mono | 14px | 400 (regular) | 1.5 | All P&L amounts, prices, percentages, R:R values in table cells and preview bar (UI-03) |
| Mono — preview | JetBrains Mono | 16px | 700 (bold) | 1.4 | Live P&L preview bar primary value (P&L dollar amount) — larger for at-a-glance read |

Typography constraints from requirements and existing components:
- Body/Label at 14px matches existing `text-sm` usage in Input.tsx, Button.tsx, and LoginForm.tsx — do not deviate.
- Monospace font is REQUIRED for all price/number values (UI-03). Apply `font-mono` Tailwind class to all `<td>` cells showing prices, P&L, percentages, and R:R.
- Base font color: `#e5e7eb` for primary text, `#6b7280` for muted text (labels, placeholders, inactive nav). Source: globals.css, Input.tsx.

## Color

| Role | Hex | CSS Variable | Usage |
|------|-----|-------------|-------|
| Dominant (60%) | `#0f0f0f` | `--background` | Page background, input backgrounds, table row backgrounds |
| Secondary (30%) | `#1a1a1a` | `--card` | Card surfaces, sidebar background, filter bar background, sticky P&L bar background, hover row surface |
| Border | `#2a2a2a` | `--border` | All borders: card edges, input borders, table dividers, section separators, P&L bar top border |
| Accent (10%) | `#00ff88` | `--accent` | Reserved list below |
| Destructive | `#ef4444` | `--destructive` | Negative P&L values, delete confirmation text ("Confirm?" button), error messages, Input error ring |
| Text primary | `#e5e7eb` | `--text` | All body text, form values, table content |
| Text muted | `#6b7280` | `--muted` | Placeholders, inactive nav links, secondary table info, pagination "Page X of Y" |

Accent (`#00ff88`) reserved for:
1. Active sidebar nav link text and 2px left border indicator (D-04)
2. Primary Button background (hover: `#00e67a`, active: `#00cc6a`) — the single primary CTA color
3. Positive P&L values in table cells and P&L preview bar (UI-02)
4. Input focus ring (`focus:border-[#00ff88] focus:ring-2 focus:ring-[#00ff88]/15`) — already established in Input.tsx
5. Toast success notification border and text
6. Upload-ready state indicator on the chart image file button (success state only)

Accent is NOT used for: general links, headings, body text, sort arrows, pagination controls, or table headers.

Source: globals.css custom properties, UI-01/UI-02 requirements, Input.tsx focus ring pattern, Button.tsx primary variant, D-04 nav active state.

## Interaction Contracts

### Trade List Page (`/trades`)

| Interaction | Behavior | Visual Response |
|-------------|----------|----------------|
| Click trade row | Navigate to `/trades/[id]` | Row hover: `bg-[#1a1a1a]` surface. Cursor: pointer. |
| Hover trade row | Reveal Edit + Delete buttons | Edit/Delete opacity: 0 → 1 via `opacity-0 group-hover:opacity-100 transition-opacity duration-150` |
| Click Delete (first) | Enter confirm state for that row only | Replace delete icon with "Confirm?" (red text) + "Cancel" (muted text) inline |
| Click "Confirm?" | Execute DELETE `/api/trades/[id]`, remove row | Row removed from DOM; show success Toast "Trade deleted." top-right |
| Click "Cancel" | Exit confirm state | Restore delete icon, no change |
| Change any filter | Immediate URL update + re-fetch (D-13) | No loading spinner on individual filter change; page re-renders via server component |
| Click pagination prev/next | Navigate to `?page=N` | Disabled state: `opacity-30 cursor-not-allowed` |

### Trade Form (`/trades/new`, `/trades/[id]/edit`)

| Interaction | Behavior | Visual Response |
|-------------|----------|----------------|
| Type in entryPrice, exitPrice, or quantity | Recalculate live P&L | Sticky bar updates immediately (useMemo, synchronous). Bar is invisible when exitPrice is absent. |
| Select assetClass = "options" | Show Options Fields section | Conditional section slides into view (no animation required, simple conditional render) |
| Select assetClass != "options" | Hide Options Fields, clear options state | Fields hidden; strikePrice/expiration/contractType/premium reset to empty string in state |
| Upload chart image | Show thumbnail preview | Below upload button: `<img>` 80px × 80px thumbnail with `object-cover rounded` |
| Submit form | Validate with Zod, then POST | Button enters loading state (Spinner). Field errors appear below each field (red text). Server error in red-bordered div above form. |
| Upload fails, form submits | Trade saves without image | Error Toast "Image upload failed — trade saved without chart." auto-dismisses 4s |
| Press Enter or comma in tags input | Add tag chip | New chip appears with ×  remove button. Tag input clears. |
| Click × on tag chip | Remove tag | Chip removed from state instantly |

### Delete Confirmation (inline, D-06)

The delete confirmation is always inline within the row — never a modal. Only one row can be in confirm state at a time. Clicking anywhere else (another row, the page) does NOT cancel the confirm state — only the "Cancel" button does. This is intentional minimal behavior for Phase 3.

## Accessibility Minimums (Phase 3)

These are non-negotiable minimums, not polish items:

| Requirement | Implementation |
|-------------|---------------|
| Form labels | Every input must have `<label htmlFor={id}>` — enforced by existing Input.tsx `label` prop requirement |
| Error announcements | Error paragraphs use `id={id}-error` + `aria-describedby` on input — already in Input.tsx |
| Icon-only buttons | Sort direction toggle and delete icon must have `aria-label` |
| Focus visible | All interactive elements must show the `#00ff88` focus ring (from Input.tsx pattern) or browser default outline — do not suppress outline without a replacement |
| Disabled states | All disabled states must have `opacity-30` or `cursor-not-allowed` visual indicator |
| Toast dismissal | Toast must be dismissible manually (close button) in addition to auto-dismiss; `role="alert"` on toast container |
