**lib/db.ts — Replace entire file with cached connection pattern (per D-05, D-06):**

```typescript
import mongoose from "mongoose"

const MONGODB_URI = process.env.MONGODB_URI!

if (!MONGODB_URI) {
  throw new Error("MONGODB_URI environment variable is not defined")
}

interface MongooseCache {
  conn: typeof mongoose | null
  promise: Promise<typeof mongoose> | null
}

declare global {
  // eslint-disable-next-line no-var
  var mongoose: MongooseCache | undefined
}

const cached: MongooseCache = global.mongoose ?? { conn: null, promise: null }
global.mongoose = cached

async function dbConnect(): Promise<typeof mongoose> {
  if (cached.conn) return cached.conn

  if (!cached.promise) {
    cached.promise = mongoose.connect(MONGODB_URI).then((m) => m)
  }

  cached.conn = await cached.promise
  return cached.conn
}

export default dbConnect
```

**lib/calculations.ts — Create with exact spec formulas (per D-11):**

Export four functions:

1. `calculatePnl(assetClass, direction, entryPrice, exitPrice, quantity, premium?)` -> number
   - stocks/crypto/forex long: `(exitPrice - entryPrice) * quantity`
   - stocks/crypto/forex short: `(entryPrice - exitPrice) * quantity`
   - options long: `(exitPrice - premium) * quantity * 100` (exitPrice = exit premium for options)
   - options short: `(premium - exitPrice) * quantity * 100`

2. `calculatePnlPercent(assetClass, pnl, entryPrice, quantity, premium?)` -> number
   - stocks/crypto/forex: `(pnl / (entryPrice * quantity)) * 100`
   - options: `(pnl / (premium * quantity * 100)) * 100`

3. `calculateRiskReward(direction, entryPrice, exitPrice, stopLoss)` -> number | undefined
   - long: `(exitPrice - entryPrice) / (entryPrice - stopLoss)` — return undefined if denominator <= 0
   - short: `(entryPrice - exitPrice) / (stopLoss - entryPrice)` — return undefined if denominator <= 0

4. `calculateTradeMetrics(trade)` -> `{ pnl: number, pnlPercent: number, riskRewardRatio?: number }`
   - Convenience wrapper that calls the three functions above
   - Accepts an object with shape `{ assetClass, direction, entryPrice, exitPrice, quantity, premium?, stopLoss? }`
   - Returns the TradeMetrics object used by the pre-save hook

Export the `TradeMetrics` interface and a `TradeForCalculation` interface for the input to `calculateTradeMetrics`.

Use explicit parameter types: `assetClass: "stock" | "crypto" | "forex" | "options"`, `direction: "long" | "short"`.
