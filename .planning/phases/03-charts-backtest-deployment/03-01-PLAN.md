Create all backend API endpoints needed for Phase 3: chart data with strategy overlays, backtest execution, health check, and CORS configuration.

Create `backend/charts/router.py` with a `GET /chart/bars/{symbol}` endpoint that:

1. Takes `symbol: str` path parameter, requires JWT auth via `Depends(get_current_user)`.
2. Gets bars from `bar_store.get(symbol.upper())`. If empty, raise `HTTPException(404, "No bars available for symbol")`.
3. Builds a DataFrame from bars: columns = timestamp (as index, converted to `pd.to_datetime`), open, high, low, close, volume.
4. Runs `compute_ema(df, period=20)` to get EMA series.
5. Runs `compute_ifvg(df)` to get IFVG state series.
6. Runs `compute_cisd(df)` to get CISD state series.

**For IFVG zone geometry:** Create a helper function `extract_ifvg_zones(df: pd.DataFrame) -> list[dict]` that replicates the core loop from `compute_ifvg` but instead of returning state strings, returns a list of zone dicts: `{"top": float, "bottom": float, "startTime": int (unix seconds), "endTime": int (unix seconds), "type": "bullish"|"bearish"}`. The zone's `startTime` is the timestamp of the bar at `start_bar` index. The zone's `endTime` is the timestamp of the bar where it got inverted (if inverted) or the last bar timestamp (if still active). The zone's `type` is "bullish" if `is_bullish` is True and it has been inverted (making the IFVG state "Bearish" — inverted bullish FVG), or "bearish" if not `is_bullish` and inverted (making state "Bullish"). Only include inverted zones that are NOT expired (bars_since_inversion <= 10). Color mapping happens on the frontend.

**For CISD level:** Create a helper function `extract_cisd_level(df: pd.DataFrame) -> float | None` that replicates the core loop from `compute_cisd` and returns the final CISD level price. After running through all bars, if `current_state` is True (Bullish), return `bear_cisd_level` (the level that was crossed to become bullish). If False (Bearish), return `bull_cisd_level`. Return `None` if the level is NaN.

**For entry markers:** Create a helper function `extract_entry_markers(df: pd.DataFrame, ifvg_states: pd.Series, cisd_states: pd.Series, ema_series: pd.Series) -> list[dict]` that iterates over bars and detects entry conditions (same logic as paper engine): Long when ifvg_state=="Bullish" AND cisd_state=="Bullish" AND close > ema. Short when ifvg_state=="Bearish" AND cisd_state=="Bearish" AND close < ema. Returns list of `{"time": int (unix seconds), "direction": "Long"|"Short"}`.

**Response format:**
```python
return {
    "bars": [{"time": int(ts.timestamp()), "open": float, "high": float, "low": float, "close": float}, ...],
    "ema": [{"time": int(ts.timestamp()), "value": float}, ...],  # skip NaN values
    "ifvg_zones": [{"top": float, "bottom": float, "startTime": int, "endTime": int, "type": "bullish"|"bearish"}, ...],
    "cisd_level": float | None,
    "markers": [{"time": int, "direction": "Long"|"Short"}, ...]
}
```

All timestamps must be Unix epoch SECONDS (not milliseconds) — lightweight-charts requires this format.

Use `import asyncio` and wrap any blocking pandas operations in `asyncio.to_thread()` if needed, but since bar_store is in-memory and compute functions are fast on small datasets, synchronous is acceptable for this endpoint.

**Create `backend/backtest/router.py`** with:

1. A Pydantic model `BacktestRequest`:
   ```python
   class BacktestRequest(BaseModel):
       symbol: str
       start_date: str  # "YYYY-MM-DD"
       end_date: str    # "YYYY-MM-DD"
   ```

2. A `POST /backtest/run` endpoint that:
   - Requires JWT auth via `Depends(get_current_user)`
   - Validates date range: `end_date - start_date <= 7 days`. If exceeds, return `HTTPException(400, "Date range exceeds the 7-day limit for 1-minute data. Shorten your range.")`
   - Validates `start_date < end_date`. If not, return `HTTPException(400, "Start date must be before end date.")`
   - Fetches 1m bars via `await asyncio.to_thread(lambda: yf.Ticker(req.symbol).history(start=req.start_date, end=req.end_date, interval="1m"))`
   - If DataFrame is empty, return `HTTPException(404, "No data available for this symbol and date range.")`
   - Renames columns to lowercase: `df.columns = df.columns.str.lower()`
   - Runs `compute_ifvg(df)`, `compute_cisd(df)`, `compute_ema(df, period=20)` on the full DataFrame
   - Iterates bar-by-bar to detect entries using the same logic as PaperTradingEngine.on_signal:
     - Long: ifvg_state=="Bullish" AND cisd_state=="Bullish" AND close > ema
     - Short: ifvg_state=="Bearish" AND cisd_state=="Bearish" AND close < ema
   - For each entry, calculates stop/target using the same formula as paper engine:
     - Long stop = min(low) over last 8 bars. Short stop = max(high) over last 8 bars.
     - Risk = abs(entry - stop). Skip if risk <= 0.
     - Target = entry +/- risk * 1.5
     - Quantity = 1000.0 / risk
   - Simulates trade outcomes: iterate subsequent bars to check if stop or target is hit first. If stop hit: pnl = -quantity * risk. If target hit: pnl = +quantity * risk * 1.5. If neither hit by end of data: mark as open (pnl = 0, excluded from stats).
   - Max 1 trade open at a time (skip new entries while a trade is open).
   - Builds equity curve: `[{"date": "YYYY-MM-DD HH:MM", "cumPnl": float}]` — one point per closed trade, cumulative sum.
   - Computes stats: `total_trades` (closed only), `win_rate` (wins/total as float 0-1), `avg_r_multiple` (average pnl per trade / risk_per_trade, or 0 if no trades).
   - Builds entry markers: `[{"time": int (unix seconds), "direction": "Long"|"Short"}]`
   - Builds bars for chart: `[{"time": int (unix seconds), "open", "high", "low", "close"}]`
   - Builds EMA for chart: `[{"time": int (unix seconds), "value": float}]` (skip NaN)

   **Response:**
   ```python
   return {
       "bars": [...],
       "ema": [...],
       "markers": [...],
       "equity_curve": [...],
       "stats": {"total_trades": int, "win_rate": float, "avg_r_multiple": float}
   }
   ```
