| sm | 8px | Compact element spacing, input padding |

- Chart container minimum height: 400px (imperative sizing requirement of lightweight-charts)

## Interaction Contracts

### CandlestickChart

- Mount inside `useEffect` with `chart.remove()` cleanup — never in render body
- Data updates via `series.setData()` and `series.update()` through `useRef` — no React state re-renders for chart data
- Chart resizes automatically via `chart.applyOptions({ width: container.clientWidth })` on window resize event, cleaned up with `removeEventListener`
- `chart.timeScale().fitContent()` called once after initial data load
- On symbol change: call `series.setData(newData)` (do not destroy and recreate the chart)
- Markers array passed as prop; applied via `createSeriesMarkers(candleSeries, markers)` after `setData()`
- CISD level line applied via `candleSeries.createPriceLine({ price, color: '#F1C40F', lineWidth: 1, lineStyle: LineStyle.Dashed, title: 'CISD' })`
- IFVG zones applied via `candleSeries.attachPrimitive(ifvgPrimitive)` after series creation; zones updated via `ifvgPrimitive.updateData(zones)` without re-attaching

### Backtest Form

- "Run Backtest" button is disabled while a backtest is in-flight (loading state)
- "Run Backtest" button shows text "Running..." while loading (no spinner icon — text change only)
- Date range inputs: `max` attribute on start date = today minus 1 day; `max` on end date = today; `min` on both = today minus 7 days
- Server-side 400 response for >7-day range displays the date range error copy in a Sonner toast (`toast.error(...)`)
- On successful backtest: results panel appears below the form without page reload; previous results are replaced

### BacktestStatsPanel

- Three stat cards in a horizontal row: Trades / Win Rate / Avg R
- On desktop (≥768px): all three in a single row
- On narrow viewports (<768px): stack vertically (single column)
- Win Rate displayed as percentage: `"62.5%"`
- Avg R displayed with 2 decimal places: `"1.43R"`
- Total Trades displayed as integer: `"24"`

### EquityCurve

- Tooltip background: `#1A1D27`, no border
- X-axis: date string formatted as `MM/DD HH:mm`; tick font-size 11px; color `#94A3B8`
- Y-axis: dollar values; tick font-size 11px; color `#94A3B8`
- Area fill: `rgba(34, 197, 94, 0.15)` (same green as bullish semantic, low opacity)
- Area stroke: `#22C55E`, 1.5px
- CartesianGrid stroke: `#2D3148` (matches border token)
- No legend displayed

### Navigation

- Backtest is a separate page (`/backtest`) accessible via a nav link in DashboardHeader
- DashboardHeader gains a second nav link "Backtest" alongside the existing logout button
- Active page link uses accent color `#3B82F6`; inactive uses muted `#6B7280`
- No modal overlays or drawers for Phase 3 — chart and backtest each live on their own route
