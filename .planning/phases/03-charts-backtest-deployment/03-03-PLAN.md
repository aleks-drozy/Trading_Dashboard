**Create `frontend/src/components/CandlestickChart.tsx`:**

Props interface:
```typescript
interface ChartBar {
  time: number  // Unix seconds
  open: number
  high: number
  low: number
  close: number
}

interface EmaPoint {
  time: number
  value: number
}

interface IFVGZone {
  top: number
  bottom: number
  startTime: number
  endTime: number
  type: 'bullish' | 'bearish'
}

interface EntryMarker {
  time: number
  direction: 'Long' | 'Short'
}

interface CandlestickChartProps {
  bars: ChartBar[]
  ema: EmaPoint[]
  ifvgZones: IFVGZone[]
  cisdLevel: number | null
  markers: EntryMarker[]
  loading?: boolean
  error?: string | null
}
```

Component implementation using `useEffect` + `useRef` pattern (imperative, NOT React state for chart data):

1. Create a `containerRef = useRef<HTMLDivElement>(null)` and `chartRef = useRef<IChartApi | null>(null)`.

2. In `useEffect` with `[bars, ema, ifvgZones, cisdLevel, markers]` deps:
   - If `chartRef.current` exists, call `chartRef.current.remove()` before recreating (handles data changes).
   - Create chart: `createChart(containerRef.current, { layout: { background: { color: '#0F1117' }, textColor: '#F1F5F9' }, grid: { vertLines: { color: '#2D3148' }, horzLines: { color: '#2D3148' } }, height: 400, width: containerRef.current.clientWidth })`.
   - Add candlestick series: `chart.addSeries(CandlestickSeries, { upColor: '#22C55E', downColor: '#EF4444', borderUpColor: '#22C55E', borderDownColor: '#EF4444', wickUpColor: '#22C55E', wickDownColor: '#EF4444' })`. Note: use `#22C55E` (UI-SPEC bullish) not `#26a69a` (research default).
   - Set data: `candleSeries.setData(bars)`.
   - Add EMA line: `chart.addSeries(LineSeries, { color: '#3B82F6', lineWidth: 1 })` and `emaSeries.setData(ema)`. Color is accent blue per UI-SPEC.
   - Add CISD price line (if `cisdLevel` is not null): `candleSeries.createPriceLine({ price: cisdLevel, color: '#F1C40F', lineWidth: 1, lineStyle: 2, title: 'CISD' })`. `lineStyle: 2` = Dashed (import `LineStyle` from lightweight-charts).
   - Add entry markers: Convert `markers` to lightweight-charts format:
     ```typescript
     import { createSeriesMarkers } from 'lightweight-charts'
     const lwMarkers = markers.map(m => ({
       time: m.time as UTCTimestamp,
       position: m.direction === 'Long' ? 'belowBar' as const : 'aboveBar' as const,
       color: m.direction === 'Long' ? '#22C55E' : '#EF4444',
       shape: m.direction === 'Long' ? 'arrowUp' as const : 'arrowDown' as const,
       text: m.direction === 'Long' ? 'L' : 'S',
     }))
     createSeriesMarkers(candleSeries, lwMarkers)
     ```
   - For IFVG zones: Use a simple approach — for each zone, create a separate `candleSeries.createPriceLine()` at the top and bottom prices with zone color. This is simpler than the full ISeriesPrimitive and visually represents the zone boundaries. Alternatively, implement a basic rectangle drawing using the series primitive approach from the research. **Preferred approach (simpler, reliable):** For each IFVG zone, add two price lines — one at `zone.top` and one at `zone.bottom` — with `color: zone.type === 'bullish' ? 'rgba(34, 197, 94, 0.5)' : 'rgba(239, 68, 68, 0.5)'` and `lineWidth: 1`, `lineStyle: 0` (Solid), `title: ''`. This visually brackets the zone. If the ISeriesPrimitive `fillRect` approach is straightforward to implement from the research Pattern 2, use that instead for proper filled rectangles. Either approach is acceptable as long as zones are visually distinguishable.
   - Fit content: `chart.timeScale().fitContent()`.

3. Add resize handler:
   ```typescript
   const handleResize = () => {
     if (chartRef.current && containerRef.current) {
       chartRef.current.applyOptions({ width: containerRef.current.clientWidth })
     }
   }
   window.addEventListener('resize', handleResize)
   ```

4. Cleanup: `return () => { window.removeEventListener('resize', handleResize); if (chartRef.current) { chartRef.current.remove(); chartRef.current = null } }`.

5. Render: Show loading state ("Loading chart..." in muted text `#6B7280` centered, 400px height) when `loading` is true. Show error state (error copy from UI-SPEC in red) when `error` is truthy. Otherwise show `<div ref={containerRef} />`.

Import types: `import { createChart, CandlestickSeries, LineSeries, LineStyle, createSeriesMarkers, type IChartApi, type UTCTimestamp } from 'lightweight-charts'`.
