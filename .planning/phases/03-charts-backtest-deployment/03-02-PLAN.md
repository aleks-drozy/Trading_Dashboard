**Create `render.yaml`** at project root with this exact content:

```yaml
services:
  - type: web
    name: trading-dashboard-api
    runtime: python
    plan: free
    rootDir: .
    buildCommand: pip install -r requirements.txt
    startCommand: uvicorn backend.main:app --host 0.0.0.0 --port $PORT
    healthCheckPath: /health
    envVars:
      - key: FRONTEND_URL
        sync: false
      - key: SECRET_KEY
        sync: false
      - key: ADMIN_EMAIL
        sync: false
      - key: ADMIN_PASSWORD_HASH
        sync: false

crons:
  - name: keep-alive
    schedule: "20 13 * * 1-5"
    command: curl -s $RENDER_EXTERNAL_URL/health
```

Notes:
- `schedule: "20 13 * * 1-5"` = 9:20 AM ET (UTC-4 EDT / UTC-5 EST — 13:20 UTC covers EDT; for EST it would be 14:20 UTC, but the cron is a safety margin anyway)
- `$RENDER_EXTERNAL_URL` is auto-set by Render to the service's public URL
- `sync: false` means values are set manually in Render dashboard, not synced from render.yaml
- `DATABASE_URL` is omitted (uses default SQLite path)

```typescript
export const API_BASE = import.meta.env.VITE_API_URL ?? ''
```

This means:
- In local dev: `VITE_API_URL` is not set, so `API_BASE = ''`, and Vite proxy handles routing to localhost:8000 (existing behavior preserved)
- In production on Vercel: `VITE_API_URL=https://<service>.onrender.com` is set as a Vercel env var, so all fetch calls hit the Render backend directly

All existing `fetchWithAuth` calls use relative URLs like `/paper/trades` which will be prepended with `API_BASE` automatically since they go through `fetchWithAuth`. But `fetchWithAuth` currently uses the URL as-is. Update `fetchWithAuth` to prepend `API_BASE`:

```typescript
export async function fetchWithAuth(url: string, init?: RequestInit): Promise<Response> {
  const fullUrl = url.startsWith('http') ? url : `${API_BASE}${url}`
  return fetch(fullUrl, {
    ...init,
    headers: { ...getAuthHeaders(), ...init?.headers },
  })
}
```

Also update `loginRequest` to use `API_BASE`:
```typescript
const res = await fetch(`${API_BASE}/auth/login`, { ... })
```
