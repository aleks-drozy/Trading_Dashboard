## Interaction Contract

### Timeframe Switch

1. User clicks a pill (e.g. "5m").
2. `setTimeframe(5)` fires immediately — pill transitions to active style (CSS `transition-colors`).
3. `useEffect` re-runs with new `timeframe` value, sets `loading: true`.
4. `fetchWithAuth('/chart/bars/SPY?timeframe=5')` fires.
5. On success: `setChartData(data)`, `setLoading(false)` — chart re-renders with 5m bars.
6. On 404 (insufficient bars): `setChartData(null)`, `setLoading(false)` — empty state shown.
7. On network error: `setError(...)`, `setLoading(false)` — error state shown.

### Symbol Switch with Timeframe Persistence

1. User clicks a different symbol pill.
2. `setSelectedSymbol('AAPL')` fires.
3. `useEffect` re-runs with `[selectedSymbol, timeframe]` — the current `timeframe` state value is preserved.
4. Request goes to `/chart/bars/AAPL?timeframe={current}` — timeframe does NOT reset to 1m.

## States and Copy

### Loading State

- Chart area shows spinner/skeleton via existing `CandlestickChart` `loading={true}` prop.
- Timeframe pills remain visible and interactive during load.
- No additional copy needed — loading is visual only.

### Empty State (no bars available for symbol)

**Heading:** none (existing pattern has no heading)
**Body copy:** "No chart data available. Add a symbol to your watchlist and wait for the first bar."
**Source:** ChartPage.tsx line 126 — pre-existing copy, unchanged.

### Empty State (insufficient bars for selected timeframe — 404 from `?timeframe=60`)

**Body copy:** "Not enough data for the 1h timeframe. Switch to a shorter timeframe or wait for more bars to accumulate."
**Color:** `#6B7280` (`--muted-foreground`)
**Container:** same `height: 400` centered flex div as the no-data state.

### Error State (network / API failure)

**Copy:** "Chart data failed to load. Check your connection and try again."
**Source:** ChartPage.tsx line 79 — pre-existing copy, unchanged.
**Color:** `#F87171` (destructive) for the error message text.

### Destructive Actions

None in this phase. The timeframe switcher is non-destructive. No confirmation dialogs required.
